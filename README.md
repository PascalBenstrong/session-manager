# Session Manager

A browser extension (Firefox and Chrome) that tracks tabs in sessions, lets you search and organize them, and cleans cookies and site data. It is written in Rust with an [egui](https://github.com/emilk/egui) UI, compiled to WebAssembly. See [spec.md](spec.md) for the requirements.

## Layout

| Path | Contents |
|------|----------|
| `src/` | **Shared Rust code.** The core (`model`, `search`, `organize`, `cleanup`, `pattern`, `state`, `protocol`, `url`) is plain Rust and unit-tested natively. `background.rs`, `platform.rs` and `ui/` build only for wasm. |
| `web/` | Shared pages and loaders: `popup.html`, `manager.html`, `background.js`, `ui.js`, and `platform-common.js` (the default `smPlatform` JS shim). |
| `icons/` | Shared icons, generated by `tools/gen-icons.mjs`. |
| `firefox/` | Firefox-only files: `manifest.json` and `platform.js` (overrides: creating tabs already discarded, site-data removal by `hostnames`). |
| `chrome/` | Chrome-only files: `manifest.json` (MV3 service worker) and `platform.js` (site-data removal by `origins`). |
| `CHANGELOG.md` | Release notes, compiled into the extension and shown on its *What's new* page. |
| `spec.md` | What the extension does (requirements). |
| `tools/` | Smoke test, mock browser API, in-browser preview, icon generator. |

The Rust code reaches the browser only through `globalThis.smPlatform`. To support another browser, add a folder with a `manifest.json` and a `platform.js` that calls `installPlatform(api, overrides)`.

## Build

Requirements:

```sh
rustup target add wasm32-unknown-unknown
cargo install wasm-bindgen-cli --version 0.2.129 --locked   # must match Cargo.lock
```

Then run:

```sh
./build.sh                 # dist/firefox and dist/chrome (release build)
./build.sh firefox         # one browser only
PROFILE=dev ./build.sh     # faster, unoptimized build
```

If `wasm-opt` (binaryen) is installed, `build.sh` runs it to shrink the wasm file further.

## Install in your browser

You don't need Node or a server. Build once with `./build.sh`, then load the `dist/` folder:

**Chrome / Edge / Brave** (stays installed):
1. Open `chrome://extensions` (`edge://extensions` in Edge).
2. Turn on **Developer mode**.
3. Click **Load unpacked** and select the `dist/chrome` folder.
4. Pin it: click the puzzle-piece icon in the toolbar, then the pin next to *Session Manager*.

**Firefox, for development** (removed when Firefox restarts):
1. Open `about:debugging#/runtime/this-firefox`.
2. Click **Load Temporary Add-on…** and select `dist/firefox/manifest.json`.
3. In `about:addons` → *Session Manager* → *Permissions*, allow **Access your data for all websites**. Cookie clean-up needs it.

**Firefox, permanently:** run `./build.sh --zip` to create `dist/session-manager-firefox.zip`, then either:
- Firefox Developer Edition / Nightly / ESR: set `xpinstall.signatures.required` to `false` in `about:config`, then *about:addons* → ⚙ → **Install Add-on From File…** → pick the zip.
- Regular Firefox: the add-on must be signed. Upload the zip as an *unlisted* add-on at addons.mozilla.org (or use `web-ext sign`), then install the signed `.xpi` it gives you.

After rebuilding, reload the extension: the ⟳ button on `chrome://extensions`, or **Reload** in `about:debugging`.

## Using it

- **Toolbar popup (quick switcher):** click the toolbar icon or press **Alt+Shift+S**. Type to search the current session (the same search syntax as below; toggle *All sessions* to widen it), use **↑/↓** to move, and **Enter** or a click to jump to the tab; the popup closes. **Esc** closes it. The header has the session picker, *Last tab*, *Load*, and the session menu. **Open manager ⛶** opens the full page.
- **Change the shortcut:** `chrome://extensions/shortcuts`, or *about:addons* → ⚙ → *Manage Extension Shortcuts* in Firefox.
- **Full manager page:** sidebar with all sessions, plus the Tabs, Organize, Snapshots & import, Cookies & data and Settings views.
- **Snapshots, saving & importing:** open *Snapshots & import* in the manager, or choose *💾 Snapshots, save & import…* from the "⋯" session menu (the popup opens the manager for this, since file pickers close extension popups). *📸 Save snapshot* in that menu saves a revision right away.

## Releasing

1. Add a `## [x.y.z] - YYYY-MM-DD` entry at the top of [CHANGELOG.md](CHANGELOG.md), with `### New` / `### Improved` / `### Fixed` sections and `- ` bullets.
2. Set the same version in `Cargo.toml`, `firefox/manifest.json` and `chrome/manifest.json`. `cargo test` fails if any of them disagree.
3. Run `./build.sh --zip`.

When users get the update, the toolbar icon shows **NEW** and the popup highlights *What's new* until the notes have been opened.

## Tests

```sh
cargo test                                         # core unit tests (native)
./build.sh && node tools/smoke-test.mjs firefox    # real wasm background against a mock browser API
node tools/smoke-test.mjs chrome
node tools/serve.mjs   # then open http://127.0.0.1:8123/tools/preview.html (add ?popup for popup size)
```

The preview runs the real background and UI together in a normal page, using seeded mock tabs. `?popup` uses the popup size, `#backup` (or another view name) opens that view, `?click=x,y;x,y` / `?hover=x,y` / `?keys=ArrowDown,Enter` simulate input, and `?clip=text` stands in for the clipboard in headless screenshots.

The UI has dark and light themes; the toggle in the header cycles System → Light → Dark and is remembered.

## Features

**Sessions**
- Opened tabs are added to the *active* session automatically. Browser-internal pages are ignored (configurable).
- Closing a tab removes it from its session. When a whole window closes, or the browser quits, its tabs are kept as *unloaded* entries instead (configurable).
- *Set active* switches the session that new tabs go to without opening any of its tabs.
- *Load* opens a session's closed tabs: unloaded/lazy, in a new window, or fully loaded.
- *Last tab* focuses the session's most recently used tab, reopening it if needed.
- You can remove a tab from its session manually; it stays open but is no longer tracked. You can also close it, or move it to another session.
- On startup, tabs are re-linked to their entries by tab ID, then by URL.

**Search** (tooltip on the search box): `host:` `domain:` `tag:` `group:` `title:` `url:` fields; `=exact` / `^exact$`, `^prefix`, `suffix$`, `*glob?`, `/regex/`, and `-negation`; `is:open|unloaded|pinned|grouped|ungrouped|tagged|duplicate`. You can also set the default field and match mode, case sensitivity, a group filter, and search all sessions. Bulk actions (tag/untag, set group, move, remove, close) apply to every match.

**Organize**
- Group the list by domain, host, group or tag.
- Re-order the browser's tabs by any of those keys, optionally as native tab groups (Chrome, and Firefox versions that expose `tabGroups`).
- Optionally re-organize automatically whenever tabs change (debounced).
- Auto rules add tags and a group to tabs whose URL matches a pattern.

**Duplicate tabs**
- **Where:** Organize → *Duplicate tabs*, the "⧉ N duplicates" badge in the Tabs view, or *⧉ Remove duplicates* in the "⋯" session menu (also in the popup).
- **What counts as the same page:** you choose which differences to ignore: `#fragment` and trailing `/` are ignored by default; `?query`, `www.` and http vs https are optional.
- **Which copy stays:** the open one, then the one in the active session, then the most recently used. Tags of the removed copies are merged into it, and their group too if the kept copy has none. Extra open tabs are closed, unless you choose to leave them open and only remove them from the session.
- **Scope:** the current session or all sessions. Search `is:duplicate` to list them first.
- **Prevent duplicates (opt-in):** opening a page that's already in the active session switches to the existing tab and closes the new one. If the saved copy is unloaded, the new tab simply takes its place. Tabs the extension opens itself (loading or restoring a session) are never affected.

**Snapshots (revisions)**
- Save the current tab list of a session as a named snapshot. Each snapshot shows how it differs from now (`+added / −removed`).
- Restore a snapshot in one of three ways:
  - **Replace:** the current list is snapshotted first, so this can be undone. Open tabs that are in the snapshot stay linked; other open tabs stay open but are no longer tracked.
  - **Add missing tabs:** only the snapshot's tabs that aren't in the session yet.
  - **Open as a new session.**
- Restored tabs can optionally be opened right away, unloaded.
- Optional automatic snapshots every N minutes. These only happen for sessions that changed. Only the last N automatic snapshots are kept; manual ones are never pruned.

**Saving to disk and importing**
- Download one session or all sessions as `.json` (optionally with snapshots), a single snapshot, or the URL list as `.txt` (comma separated). *Copy URLs* puts that list on the clipboard.
- Import from a file (*Open file…* or drag-and-drop onto the page), from the clipboard, or by pasting into the text box.
  - **Session files** become new sessions; nothing is overwritten.
  - **URL lists:** URLs can be separated by commas, newlines, spaces or semicolons. Bare hosts like `example.com/x` get `https://`, duplicates and non-URLs are skipped, and commas inside URLs (`?ids=1,2`) are kept. Choose to add them to the current session or a new one, and whether to open them unloaded right away.

**Cookies and site data**
- Clean cookies, cache, localStorage, IndexedDB and service workers for:
  - a host, domain (including subdomains), URL prefix, glob or regex
  - all open tabs
  - all domains
- A *keep* list protects domains from cleaning.
- Saved rules can run on a timer (`alarms`) and/or delete matching cookies as soon as a site sets them.
- A log records recent clean-ups.

## Known limitations

- **Per-site cache (Firefox):** Firefox can't clear the HTTP cache for individual sites. Per-site clean-ups there skip the cache and show a warning; *All domains* clears the whole cache.
- **"Clean whenever a new value is set":** only cookies can be watched, through `cookies.onChanged`. Other storage has no change events that extensions can observe.
- **Domain grouping:** the domain is a heuristic "registrable domain" (it handles `co.uk`-style suffixes) rather than the full Public Suffix List.
- **Chrome tab loading:** Chrome can't create tabs that are already discarded, so "unloaded" tabs are created and then discarded right away. They may start loading briefly.
- **Clipboard permission:** *Paste from clipboard* uses the `clipboardRead` permission (shown at install as "read data you copy and paste"). Pasting with Ctrl+V into the import box works without it.
- **Bundle size:** the wasm file is about 6 MB, mostly egui and its fonts. The background and UI share the same module.
